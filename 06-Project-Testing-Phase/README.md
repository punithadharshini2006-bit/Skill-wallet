# Project Testing Phase

## Project Name
Skill-wallet

## Purpose of Testing

Testing is performed to identify errors and verify that the system functions according to the requirements.

## Testing Types

### Unit Testing
Individual modules are tested separately.

### Integration Testing
Different modules are tested together.

### System Testing
The complete application is tested.

### User Interface Testing
The interface is checked for usability and navigation.

## Test Cases

| Test Case | Expected Result |
|---|---|
| User Registration | User should be registered |
| User Login | User should be able to login |
| Add Skill | Skill should be added |
| View Skill | Skill should be displayed |
| Update Skill | Skill should be updated |
| Delete Skill | Skill should be removed |
| Logout | User should be logged out |

## Expected Result

The application should work correctly without major errors.
